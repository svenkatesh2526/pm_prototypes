# HomePlate Configurator Tooling — FI Prototype

Clickable, self-contained HTML prototype for the Home Plate Tooling for Product
Configurator Front-End Setup (FI market). Open `index.html` in any browser — no
build step or dependencies.

Contents:
- `index.html` / `Prototype_HomePlate_Configurator_FI_2026-06-30.html` — the prototype
  (three design variations behind a switcher: stepped modal, side drawer, full-page tabs).
- `PRD_HomePlate_Configurator_Tooling_2026-06-29.docx` — the product requirements doc.

Demo product: Chelsea Nike Home Stadium Shirt 2026-27 (PID 203532222).
